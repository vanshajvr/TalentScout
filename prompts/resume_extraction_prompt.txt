{resume_text}

Extract the following fields as strict JSON, with no extra commentary:
{{
  "email": "<email or null>",
  "phone": "<phone number or null>",
  "location": "<city/location or null>",
  "experience": "<total years of professional experience as a number, or null>",
  "role": "<most recent job title and company, e.g. 'Research and Automation Intern at XYZ Corp', or null if company isn't listed>",

- If a field can't be confidently determined, use null (or an empty array for tech_stack).

- linkedin/github may similarly appear as "[link: https://linkedin.com/in/...]"
  or "[link: https://github.com/...]" rather than plain text — extract the
  full URL from the link marker if the visible label alone isn't a real URL.
- Output ONLY the JSON object, nothing else.
